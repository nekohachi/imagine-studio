# 06. 漫画

Web 投稿と印刷の両対応。原稿は常に印刷解像度で持ち、Web は書き出し時に縮小する。

## 作品設定

- 用紙: B5 / A5 / B4 原稿用紙 / 同人誌(A5、B5)/ 縦スクロール(幅 800px 前後、高さ可変)/ カスタム。
- 仕上がり(複数登録): 印刷用(裁ち落とし 3mm、ノド、基本枠、トンボ)と Web 用(幅 1200〜2000px のページ形式、または縦スクロール)。書き出し時に選ぶ。
- 解像度: モノクロ 600dpi、カラー 350dpi が既定。
- 綴じ方向(右綴じ / 左綴じ)、ノド幅。

## メモリ(iPad mini で 600dpi を成立させる)

B4 の 600dpi は 6071×8598 で約 52 メガ画素。モノクロ 1ch なら 1 レイヤー最大 52MB、カラー 4ch なら 208MB。

対処は 03 のとおり。1ch、スパースタイル、LRU 退避。原稿は余白が多いので実際のタイル数は最大値の半分以下になる。実測は 11 のチェック項目。

## レイヤー

- 線画とトーンはモノクロ(A8)レイヤー。ベタとホワイトも A8。
- カラー原稿は RGBA8。
- コマ枠フォルダ(CLIP STUDIO 方式): フォルダがベクターの枠を持ち、子レイヤーを枠でクリッピングする。枠線の太さ、コマ間の天地と左右の間隔は作品単位。
- コマの分割は輪で縦 / 横 / 斜めを選び、線を引いて割る。枠の頂点は後からドラッグできる。

## ペン入れ

- ベクターレイヤー(05 のブラシをストロークとして保存)。
- ベクター消しゴム: 交点まで消す / 触れた線を消す / 通常。
- 線幅の後編集(太く、細く、均一)、入り抜きの後調整、線の単純化。
- 定規: 直線 / 平行 / 放射 / 同心円 / パース(1〜3 点)/ 対称(2〜8 軸)。3D 参照レイヤーのカメラからパース定規を作れる。

実装(フェーズ 5a): ベクターレイヤーは線を入力点のまま持つ(ブラシ定義の JSON、色、[x, y, 筆圧, 時刻, 傾き] × n)。
画素はその描画キャッシュで、`canvas-core/vector.rs` の CPU ラスタライザが GPU のダブシェーダと同じ式で焼く
(描いている間は GPU、ペンを離したら CPU。両者は同じ色になることを Chromium で確かめている)。
描き直しは消えた線の範囲だけ。ベクター消しゴムは線を切る / 丸ごと消す / 交点まで消すの 3 種。
線幅の後編集(太く / 細く / 均一)は全線の描き直し。履歴はタイル差分に線の入れ替え(splice)を添えて持つ。
塗り・変形・色調補正は線とずれるのでベクターレイヤーでは断り、「ラスタライズ」で画素にしてから使う。
`.imst` には `pages/0/vectors/<id>.json` として入る。

実装(フェーズ 5b): 定規は `apps/web/src/ruler.ts` の純関数で、描画ワーカーがストロークの前段で入力点を吸着させる
(直線 / 平行 / 放射 / 同心円 / パース 1〜3 点)。パースは描き始めの 6px の動きで向きを選び、それまでの点は貯めてから流す。
対称はワーカーが写しの数だけストロークエンジンを並べて同時に描き、焼き込みは 1 回(ベクターは N 本を 1 履歴で足す)。
定規の位置は設定(localStorage)に持ち、オン / オフを切り替えられる。配置はキャンバスの輪「定規」→ パネル → タップ。
表示はメインスレッドの SVG オーバーレイ。つまみのドラッグ編集と 3D カメラからのパース定規はこれから。

## トーン

- 塗りレイヤーに「網点化」効果を非破壊で乗せる。線数(60 / 65 / 70 など)、濃度、角度、形(円 / 線 / ノイズ)、グラデトーン。
- 画面表示はズーム倍率に合わせて描く(モアレを避ける)。
- 書き出し: 印刷は出力解像度で網点化して 2 階調。Web は濃度をグレーで出す選択肢を持つ(網点のまま縮小するとモアレが出る)。
- トーン削り: トーンレイヤーのマスクをブラシで削る。

## フキダシとテキスト

- フキダシはベクター図形 + しっぽ。種類(楕円 / 角丸 / 雲 / ギザギザ / 線なし)、しっぽの形。中のテキストに合わせて伸縮。
- テキスト: 横書き / 縦書き、ルビ、フォント、字間、行間、禁則処理、縦中横。縦書きは自前レイアウト(工数大)。
- フォントはシステムフォント + 作品に同梱したフォントファイル。

## 効果線

- 集中線: 中心、本数、長さのばらつき、太さの入り抜き、内側の空き(円 / 楕円 / 自由)。
- 流線: 方向、間隔、長さのばらつき、カーブ。
- どちらも非破壊のベクター効果。ラスタライズは書き出し時。

## ベタ、ホワイト、塗り

- 囲って塗る、塗り残し検出(閉領域のうち未塗りを強調)、隙間閉じ(px)、参照レイヤー指定。
- ドット絵アプリの塗りつぶし実装を拡張する。

## ページ管理

- ページ一覧はサムネイル。並べ替えはドラッグ、追加 / 複製 / 削除 / 見開きは輪。
- ネーム: 低解像度の下書きページを本番ページに「下敷き」として重ねる。
- iPad mini でネーム、MovinkPad で本番という使い分けを想定。同期は Firebase かファイル。

## 書き出し

| 先 | 形式 |
|---|---|
| 印刷(モノクロ) | 2 階調 TIFF / PSD、ページ束ね PDF |
| 印刷(カラー) | RGB PSD、PDF。CMYK は P3 以降 |
| Web(ページ) | PNG / JPG、幅指定で縮小 |
| Web(縦スクロール) | 縦結合 PNG / JPG、高さ上限で自動分割 |
