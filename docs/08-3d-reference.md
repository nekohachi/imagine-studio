# 08. 3D 参照レイヤー

CLIP STUDIO との差は「モード切替がない」「ギズモを指で狙わない」「輪が文脈で決まる」の 3 点。
操作体系は macbeth(`claude/tablet-3d-modeling-app-f6b1x5`)のものをそのまま持ち込む。

## 位置づけ

- 描く対象ではなく、下絵、パース、ポーズの参考。
- 3D 参照レイヤーを選んでいるときだけ、キャンバス上の指が 3D へ行く。ペンは常に 2D で描く。モードボタンは作らない。
- three.js は 3D レイヤーを初めて追加したときに動的 import する。

## 読み込み

| 形式 | 用途 |
|---|---|
| glTF / GLB | 一般(新規実装) |
| VRM | 人型。ボーンが規格化されているので IK とポーズプリセットが作りやすい |
| OBJ | 静物。macbeth の読み込みを流用 |

FBX は対象外。

## カメラ(macbeth 準拠、変更なし)

- 指 1 本: モデル上ならツール、外ならタンブル。置いた直後の 5px は回さない。
- 指 2 本: パンとズーム同時。合計 10px で確定。ロールなし。
- ピボットは置いた瞬間に 1 回だけ決める。優先順は選択の中心 → 指の下の面 → オブジェクト中心 → 全体中心。
- F: タップでフレーム、押しながらピンチで選択中心固定ズーム。
- SHF を押しながら回すと正面 / 真横 / 真上に吸着。生の角度を別に積んで吸着値だけカメラへ入れる。
- 3 本指長押しでカメラの輪(7 ビュー + カメラ保存)。保存カメラは輪の下の一覧。
- 「指はカメラだけ」の設定を引き継ぐ。
- マウス: Maya 準拠(Alt + 左 / 中 / 右)、右クリックで輪、ホイールでドリー。

## 選択と変形

- タップで 1 つ選ぶ。SHF で足し、CTL で除く。
- 3 本指ジェスチャ: つまむ = 拡縮、スワイプ = 軸に沿った移動、親指と残り 2 本のてこ = 5 度刻みの回転。開始時に一番大きい量で決め、途中で入れ替えない。
- 軸固定スケール: ALT を押しながらつまむと、一番離れた 2 本の指の並びを 45 度境で縦か横に倒し、参照枠の 1 軸に写す。人形の頭身調整や小物の寸法合わせに使う。
- ユニバーサルマニピュレータ(当たり 1.8 倍)は流用するが、参照用途では既定オフ。輪から出す。
- ドラッグ開始は 12px 動くか、3px 動いて 300ms。

## ポーズ

- VRM の標準ボーンに IK。関節をタップしてドラッグ。
- 手と全身のプリセットは輪の下の一覧。
- ポーズとカメラはフレームごとにキーを持て、キー間を補間する(中割りの参考)。

## 輪(1 本指長押し、3D レイヤー選択中)

配置 / 移動 / 回転 / 拡縮 / ポーズ / カメラ保存 / 線画に焼く / 影をトーンに焼く。
一覧: 保存カメラ、ポーズプリセット。

## 2D との連携

- カメラを保存すると、その消失点がキャンバスのパース定規になる。
- 「線画に焼く」: 輪郭線(法線と深度の差分)を A8 のラスターレイヤーへ。線幅、しきい値。
- 「影をトーンに焼く」: シェーディングを濃度として塗りレイヤー + 網点化へ。
- 焼いた後も 3D レイヤーは残る。

## Undo

- macbeth のシーン全体スナップショットは使わず、2D と同じ差分履歴に統一する。

## 新規に書くもの

glTF / VRM 読み込み、IK、焼き込み、パース定規連動の 4 つ。それ以外は macbeth のコピー。
