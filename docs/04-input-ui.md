# 04. 入力と UI

## 常駐 UI(Procreate 配置)

```
+------------------------------------------------------------------+
| ギャラリー  アクション  調整  選択  変形   |  ブラシ 指先 消しゴム レイヤー カラー |
+------------------------------------------------------------------+
| |サイズ|                                                          |
| |     |                                                          |
| |不透明|                   キャンバス                              |
| |     |                                                          |
| | U R |                                                          |
|                                                                   |
| SHF  F  CTL  ALT                                                  |
|          DEL                                                      |
+------------------------------------------------------------------+
```

- 上バー: Procreate と同じ並び。タップで現在のサブツールのオプションが横からカットイン。長押しで輪。アイコンは今の中身に追従する(macbeth のツール列の規則)。
- 左レール: 縦ゲージ 2 本(ブラシではサイズと不透明度、選択では境界のぼかしと許容値、3D ではソフト選択の強度と範囲)と Undo / Redo。
- 左下: 修飾ボタン SHF / F / CTL / ALT、ALT の下に DEL。タップでオン / オフ、長押し中だけ効き、左へずらして離すとロック。当たりは 44px 以上。
- iPad mini(8.3 インチ)では上バーのラベルを消してアイコンだけにし、パネルはボトムシートで開く。
- Windows ではドッキングパネル(ドット絵アプリの実装)とキーボードショートカットを足す。
- 4 本指タップで全 UI 非表示。

## 修飾ボタンの割り当て(2D)

| ボタン | 効き |
|---|---|
| SHF | 直線。ブラシで押しながら引くと直線、図形では正方形 / 正円、選択では追加 |
| CTL | 角度スナップ(45 度刻み)。選択では除外。変形では比率固定 |
| ALT | スポイト。押しながらタップで色を拾う。塗りでは「隣接のみ」切替 |
| F | 全体表示。押しながらピンチで選択中心固定ズーム。押しながらドラッグで矩形選択 |
| DEL | 選択範囲の消去 / 選択レイヤーの削除 |

修飾ボタンの長押しで「説明だけの輪」を出す。指は下へ素通りする。

## 輪(ラジアルメニュー)

macbeth の `radial.ts` を正とする。数値はそのまま使う。

| パラメータ | 値 |
|---|---|
| 形 | 8 方位固定。外径 176px、内径 56px、無効域 42px(ハブに戻すとキャンセル) |
| 区画の選択 | 14px 動くまで選ばない |
| ビューポートからの呼び出し | 400ms の長押し。12px 動いたら取消 |
| ツール列からの呼び出し | 200ms の長押し、または 24px 引いたら即開く。長押し中に指がぶれても消えない。動かさず離せばタップ |
| 画面端 | 大きさはそのままで画面内へ寄せ、押した点と輪の中心を線でつなぐ。向きは常に輪の中心から測る |
| 誤爆防止 | 開いた時点で指が乗っている区画は、出るか 25px 動かすまで選ばない |
| 一覧 | 輪の下に可変長の一覧を付けられる。第 2 リングは作らない |
| 触覚 | 区画が変わると 6ms 振動。pointercancel では実行しない |

## ジェスチャ(macbeth の判定値)

| 操作 | 判定 |
|---|---|
| 2 本指ダブルタップ | Undo。120ms 以内に着地、12px 以内、300ms 以内に離す |
| 3 本指ダブルタップ | Redo |
| 2 本指ドラッグ / ピンチ | パンとズームを同時処理。重心の移動とピンチ量の合計が 10px で確定。回転は 2 本指のひねりで、15 度以内はスナップ |
| 指が減ったとき | 残った指でキャンバスを動かさない |
| 4 本指タップ | UI 非表示 |
| ペンのダブルタップ(Pencil) | 消しゴム切替(設定で変更可) |
| ペンのスクイーズ(Pencil Pro) | 文脈の輪を開く |

## 入力パイプライン

1. `pointerdown / move / up / cancel` をメインスレッドで受ける。`setPointerCapture` を使う。
2. `getCoalescedEvents` で間引かれた点を全部取る。`getPredictedEvents` があれば先行点として別に渡す。Chrome では `pointerrawupdate` も購読する。
3. 点列 { x, y, pressure, tiltX, tiltY, time, pointerType, predicted } をワーカーへ転送する。フレームごとにまとめて送る。
4. ワーカー側で brush-core に流し、ダブを生成、ストロークバッファに描く。先行点で描いた分は確定点が来たら描き直す。
5. 指のタッチはジェスチャ専用。ペンを検出した後の指は描画に使わない(パームリジェクション)。ペンを持たないときは設定で指描きを許可する。
6. 指で描くときは速度から筆圧を作る(EMA 0.3、速いほど細く)。

## ブラシライブラリ(Procreate 参考)

- 左にカテゴリの縦列(鉛筆、ペン、マーカー、水彩、油彩、エアブラシ、テクスチャ、消しゴム、ユーザー)。
- 右にプレビュー付きの一覧。長押しで輪(お気に入りへ、複製、削除、共有)。
- ブラシスタジオ: 形状 / グレイン / 動的(筆圧、傾き、速度) / ウェット / 色の揺らぎ / 手ブレ補正 / 入り抜き。設定は JSON で保存。

## カラー

- 色相環 + 三角(SAI)と、HSB スライダー、パレット(固定 24 色 + ユーザー)、履歴。
- メイン色とサブ色。X キーまたは 2 本指タップ(カラーパネル上)で入替。
- 輪の下の一覧にパレットを並べる。
