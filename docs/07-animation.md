# 07. アニメ(手描き)

対象は手描きアニメ。クリップ編集と音声トラックは作らない。

## タイムライン

- ドット絵アプリの「レイヤー × フレームの格子」を踏襲する(Aseprite 方式)。
- 列がフレーム、行がレイヤー。セルは `layerId:frameIdx` で引く。
- フレームごとの表示時間(ms)。fps は作品設定(8 / 12 / 24 / 30)で、表示時間はその倍数にスナップ。
- 秒ベースの目盛りをヘッダに出す。
- タグ(範囲 + ループ / 往復)。
- セル共有(リンクセル): 同じ画素を複数フレームで使う。描くと全部に反映。
- 格子は下部のドックに置く。iPad mini ではボトムシート。

## オニオンスキン

- 前後 N 枚、色分け(前は赤、後は緑)、不透明度の減衰。
- 表示はミップ付きの合成で、原寸タイルを触らない。

## カメラレイヤー

- パンとズームと回転のキーフレームを持つレイヤー。書き出し時だけ適用し、作業中はオン / オフで確認。
- 中割りの参考に 3D 参照レイヤーのカメラと連動できる。

## 中割り補助

- ライトテーブル: 任意のフレームを任意の不透明度で重ねる(オニオンとは別)。
- タイムリマップ: 範囲を選んで表示時間を一括変更(2 コマ打ち、3 コマ打ち)。
- 自動中割りは作らない。

## 音声

- 参照用に音声ファイルを 1 本読み込み、波形をタイムラインに重ねる。再生はフレームに同期。
- トラック編集はしない。

## 書き出し

- GIF、APNG、WebM / MP4(WebCodecs。無ければ連番 PNG)、連番 PNG、スプライトシート(ドット絵モード)。
- 動画の取り込みはフレーム抽出のみ(ドット絵アプリの実装を流用)。

## 既存実装の流用

- 格子 UI、タグ、オニオン、fps スライダー、GIF / Aseprite 書き出しはドット絵アプリから。
- 全体スナップショット Undo だけは差分方式に置き換える。
