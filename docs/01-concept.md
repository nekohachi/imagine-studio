# 01. コンセプトと設計思想

## 一言で

**キャンバス以外は消える。必要なものは長押しで指の下に来る。**

Procreate の常駐 UI は上バーと左のスライダーだけに絞り、それ以外の操作はすべて文脈依存の「輪」(長押しのラジアルメニュー)に寄せる。

## 4 つのツールからの役割分担

| 参考にするもの | 持ってくるもの |
|---|---|
| SAI | 書き味。手ブレ補正(ひも方式)、筆圧カーブ、入り抜き、低遅延、ストロークバッファ(1 ストローク内で不透明度が重ならない) |
| Photoshop | 機能の網羅。合成モード、調整レイヤー、マスク、選択系、変形、フィルタ、PSD 互換 |
| CLIP STUDIO | イラストと漫画。ベクターレイヤー、ベクター消しゴム、定規(パース、対称、平行)、トーン、コマ枠フォルダ、フキダシ、縦書き |
| Procreate | UI の密度。上バー、QuickMenu、ブラシスタジオ、ブラシライブラリ、ジェスチャ体系 |

## 自作アプリから継承する原則

### ドット絵アプリ(pixel-art-tool)から

- ツールは「グループ」単位。タップで現在のサブツール、長押しでグループ内切替。
- レイヤー × フレームの格子でアニメを管理。オニオンスキン、タグ、フレーム表示時間。
- 変換(画像や動画からの取り込み)は非破壊で後から再調整できる。
- 自前実装の GIF、Aseprite、gzip、Firebase 同期。

### 3D モデリングアプリ(macbeth)から

- 輪の体系。8 方位固定、端寄せ、誤爆防止、引いたら即開く、輪の下の一覧、説明だけの輪、指の本数ごとの輪。
- 左下の修飾ボタン(SHF / F / CTL / ALT)。長押し中だけ効き、左へずらすとロック。
- 左レールの縦ゲージ 2 本と Undo / Redo。
- カメラ操作、ピボットの決め方、3 本指ジェスチャ、軸固定スケール(3D 参照レイヤーでそのまま使う)。
- ドック(縦横持ちで別々に保存)、HUD、ベンチ画面。

### 以前のお絵描き設計(DESIGN.md)と brush-core から

- ブラシのパイプライン: 補間 → スタビライザー → 予測入力 → スタンプ → ストロークバッファ → 合成。
- 256×256 スパースタイル、LRU 退避、タイル差分 Undo、JSON によるブラシ定義。
- brush-core(純 Rust、約 800 行、テスト付き)はそのまま移植する。

## やらないこと

- ネイティブ UI(SwiftUI / Compose / Flutter)。
- 16bit / リニア合成(設計で塞がないが実装しない)。
- 動画編集(クリップ、音声トラック)。
- 3D モデリング(macbeth の仕事)。Imagine Studio の 3D は参照専用。
- CMYK 変換(P3 以降に回す。印刷所の RGB 入稿を前提にする)。
- フレームワーク、状態管理ライブラリ。

## モード

モードは作らない。作品の種類(イラスト / 漫画 / アニメ)で UI を切り替えず、使う機能(ページ、コマ枠、タイムライン、3D)を足したときにだけ、その UI が現れる。

唯一の例外は「ドット絵モード」で、アンチエイリアスなし、整数ズーム、固定パレットの 3 点をまとめて切り替える。既存のドット絵アプリの置き換えではなく、同じ輪で描けるようにするための互換モード。
