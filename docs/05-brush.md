# 05. ブラシエンジン(SAI の書き味)

## パイプライン

```
入力点 → 補間(Catmull-Rom) → スタビライザー(ひも) → 予測点の仮描画
  → ダブ生成(間隔、散布、筆圧、傾き、速度) → ストロークバッファ(浮動小数)
  → ストローク終了時に 1 回だけ 8bit へ合成
```

## brush-core からの移植(そのまま使う)

- `InputPoint` / `Stamp` のインターフェース。
- Catmull-Rom(uniform)の逐次補間。1〜2 点遅れで区間を確定、分割数は弧長から決める。ゼロ長セグメントは捨てる(折り返しノイズの原因)。
- ひも方式のスタビライザー。強度は半径 px(0〜40)。終端で実ペン位置まで線を届かせる drain は必須。
- 円形ダブの等間隔配置。間隔は半径 × 比率(既定 0.2)。残距離をセグメントをまたいで持ち越す。
- 距離場 smoothstep の AA(約 1.5px)。
- テスト約 25 件。

## 拡張するもの

| 項目 | 現状 | 拡張 |
|---|---|---|
| 筆圧カーブ | ガンマ 1 本(既定 1.4) | 点を打つ任意カーブ。サイズ用と不透明度用を別に持つ。最小サイズ比 |
| 入力 | x, y, pressure, time | 傾き(tiltX / tiltY)、速度、予測フラグを追加 |
| 入り抜き | 筆圧依存のみ | 入りと抜きの長さを専用パラメータで持つ(SAI の「入り」「抜き」) |
| ダブの形 | 円のみ | 楕円(傾きで潰す)、テクスチャチップ、回転(進行方向 / ランダム / 傾き方向) |
| 散布 | なし | 位置、サイズ、不透明度、色相の揺らぎ |
| 混色 | なし | 周辺色のサンプリング + 混合率 + 水分量 + 色延び(SAI の水彩、マーカー)。汚れた矩形の中だけ計算 |
| グレイン | なし | ストローク固定 / キャンバス固定のテクスチャ乗算 |
| 定義 | Rust 構造体 | JSON で保存。ブラシスタジオで編集 |
| スタビライザー | ひものみ | 移動平均を前段に足せる(軽い補正用) |

## ストロークバッファ

- 浮動小数(CPU 側 f32、GPU 側は RGBA8 を 2 枚使った疑似精度ではなく、ダブ数で律速しつつ RGBA8 に描く。精度が足りない場合はこのバッファだけ RGBA16F を試す。09 で計測して決める)。
- ストローク中は「下まとめ + ストロークバッファを編集中レイヤーに乗せたもの + 上まとめ」の 3 枚合成で表示。
- 終了時にストロークの不透明度を掛けて編集中レイヤーへ焼き込む。同一ストローク内で不透明度が重ならない。
- 消しゴムは「焼き込みをアルファ減算にしたブラシ」。

## 低遅延

- 予測点で先に描き、確定点が来たら予測分を消して描き直す。予測分は別バッファに持つ。
- 描画は rAF ごとに 1 回。120Hz では 8ms。
- Chrome では `desynchronized: true`。
- 目標遅延は 09 の表。

## ドット絵モード

- AA なし、サブピクセル配置なし、ダブは整数座標、サイズは整数。
- 既存ドット絵アプリの「きれいな角度の斜め線」(CTL)を移植。

## 評価

- ゴールデン画像テスト: 同じ入力ログから同じ画像が出ること。入力ログは実機で録る。
- 実機の評価チェックリスト(DESIGN.md のものを 11 に移す)。
- 書き味の最終判断は MovinkPad Pro 14 で行う。iPad mini は遅延とメモリの下限確認。
