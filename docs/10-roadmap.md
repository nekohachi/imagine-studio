# 10. ロードマップ

フェーズ 0〜4 が MVP。5 以降は順序を入れ替えられる。

## 機能の優先度

### P0(MVP)

ラスターレイヤー、合成モード(通常 / 乗算 / スクリーン / オーバーレイ / 加算 / 減算 / 焼き込み / 覆い焼き / 比較明 / 比較暗 / 差 / 色相 / 彩度 / カラー / 輝度)、不透明度、クリッピング、マスク、グループ、選択(矩形 / 投げ縄 / クイック / 自動 / 色域)、変形(移動 / 拡縮 / 回転 / 自由変形 / ゆがみ)、塗りとグラデ、スポイト、調整レイヤー(色相彩度 / 明るさコントラスト / レベル / トーンカーブ)、ぼかしとシャープ、画像サイズとキャンバスサイズ、Undo / Redo、PSD、PNG / JPG。

### P1(イラストと漫画)

ベクターレイヤー、ベクター消しゴム、定規、モノクロレイヤー、コマ枠、トーン、ベタ、テキスト、Liquify、フィルタ拡充、非破壊変換(既存資産)。

### P2(漫画の仕上げとアニメ)

ページ管理、フキダシ、縦書き、効果線、Webtoon 書き出し、タイムライン、オニオン、カメラレイヤー、動画書き出し。

### P3(3D と周辺)

3D 参照、CMYK、ドット絵モード、同期。

## 既存コードで変える点

- 単一 HTML(ドット絵アプリの 4757 行)は使わない。必要な関数(GIF、Aseprite、gzip、塗りつぶし、格子 UI)だけ ES modules に切り出して持ってくる。
- グローバル変数の状態はドキュメントストアに集約する。
- 全体スナップショット Undo は差分方式に。
- `Uint32Array` の全面バッファはタイルと GPU テクスチャに。
- macbeth の輪、修飾ボタン、ドック、HUD、ジェスチャ判定、ベンチ画面はコピーして `packages/ring` に置く。
