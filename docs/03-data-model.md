# 03. データモデル

## 階層

```
Work(作品)
  settings: 用紙 / 仕上がり(複数) / fps / 色空間
  pages[]: Page
  brushes, palettes, 3D アセット(作品に同梱)

Page(ページ。イラストとアニメは 1 ページ)
  width, height, dpi
  layers: Layer ツリー
  frames[]: { durationMs, name }
  cels: Map<"layerId:frameIdx", CelRef>
  tags[]: { from, to, mode: loop | pingpong }
  guides: 定規、トンボ、基本枠

Layer
  id, name, type, visible, locked, opacity, blend, clip, mask?: Cel
  type ごとの付加データ(下記)
  children[](group と frame-folder のみ)

Cel(1 レイヤー × 1 フレームの画素)
  format: RGBA8 | A8(モノクロ 1ch)
  tiles: Map<tileKey, Tile>   空タイルは持たない
  mips: [Map, Map]            1/2, 1/4。遅延生成、汚れたら破棄
  linkedTo?: CelId            セル共有(複数フレームで同じ画素)
```

## レイヤー種別

| type | 内容 | 画素 |
|---|---|---|
| raster | 普通のラスター | RGBA8 または A8 |
| vector | ストロークの集合(点列 + 筆圧 + ブラシ参照)。ベクター消しゴム、線幅後編集に対応 | 表示用にラスタライズしたキャッシュ |
| group | フォルダ。合成モードは通過 or 通常 | なし |
| adjustment | 色相彩度 / 明るさコントラスト / レベル / トーンカーブ / 階調化 / 2 値化。下のレイヤーに非破壊で効く | なし(マスクのみ) |
| fill | 単色 / グラデ。トーン効果(網点化)はこの上に乗る | なし |
| shape | 矩形 / 楕円 / 多角形 / 矢印 / 星(ドット絵アプリの図形レイヤーを継承) | なし |
| text | 横書き / 縦書き、ルビ、フォント、字間、行間、禁則 | 表示用キャッシュ |
| frame-folder | コマ枠フォルダ。ベクターの枠を持ち、子をクリッピングする | なし |
| balloon | フキダシ。ベクター図形 + しっぽ、中の text と連動 | なし |
| effect-lines | 集中線 / 流線。中心、本数、長さのばらつき、入り抜き | なし |
| reference-3d | 3D 参照。シーン、カメラ、ポーズ(フレームごとにキーを持てる) | なし。焼き込みで raster を生む |
| reference-image | 参照画像(非破壊変換の入口) | 変換結果のキャッシュ |

マスクはどの種別にも 1 枚付けられる(A8 の Cel)。クリッピングは直下のレイヤーに対して効く。

## タイル

- 256×256。キーは `(tx, ty)`。
- 画素はプリマルチプライド RGBA8、または A8。ヘッダに `format` を持ち、将来の形式追加を塞がない。
- GPU 側は同じ大きさの RGBA8 / R8 テクスチャ。アトラスにまとめてバインド回数を減らす。
- ダーティフラグはタイル単位。ストローク中はダーティタイルの集合が「汚れた矩形」になる。
- LRU: 表示に関わらないタイルは、メモリ上限(09 で端末ごとに定義)を超えたら IndexedDB へ退避する。退避したタイルはキーだけ残す。

## Undo / Redo

- 1 操作 = { 変更前タイルの集合, 変更後タイルの集合, メタ情報の差分 }。
- ストロークはタイル差分。レイヤー操作(並び替え、プロパティ)はメタ差分だけ。結合や変形は両方。
- 上限は件数ではなく MB。超えたら古い差分から IndexedDB へ退避し、さらに超えたら捨てる。
- 既存 2 アプリの全体スナップショット方式は採用しない。

## ファイル形式 `.imst`

- zip(無圧縮 store + 画素ブロックだけ deflate)。macbeth の `.mbz` と同じ考え方。
- `manifest.json`(版、作品設定)、`pages/N/page.json`(レイヤーツリー、フレーム、タグ)、`pages/N/cels/<celId>/<tx>_<ty>.bin`(タイル)、`assets/`(ブラシ、3D、フォント参照)。
- タイル単位で保存しているので、自動保存は変更タイルだけ書き直せる。
- 旧ドット絵アプリの `.pxproj` v2 は読み込みだけ対応する。
