# 00. 決定事項

設計の議論で確定した方針を一覧にする。以降の文書はすべてこの表を前提にする。
変更するときはこの文書を先に直し、理由を「経緯」に残す。

| 項目 | 決定 | 理由の要点 |
|---|---|---|
| 製品名 | Imagine Studio | リポジトリは `imagine-studio`(GitHub Pages の URL になるため小文字ハイフン) |
| 位置づけ | SAI の書き味、Photoshop の機能、CLIP STUDIO のイラスト・漫画機能、Procreate の UI 密度を 1 つに統合 | 既存のドット絵アプリと 3D モデリングアプリの UI 思想(長押しの輪)を引き継ぐ |
| 対象端末 | iPad mini(iPadOS Safari、Apple Pencil)と Wacom MovinkPad Pro 14(Android 15 Chrome、Pro Pen 3)。Windows は Chrome / Edge で動けばよい | 所有端末が主戦場。MovinkPad が本番、iPad mini はネームと下書き |
| 実装基盤 | PWA + WASM。UI は TypeScript + Vite、コアは Rust を WASM 化、描画は WebGL2 | 既存資産(輪、タイムライン、ブラシコア)を全部活かせる。1 コードで 3 OS |
| 配布 | PWA のみ。個人使用が基本。App Store は出来に満足してから検討 | ストア対応(Capacitor)は設計から外し、必要になった時に包む |
| 色深度 | 8bit 固定。計算は浮動小数、保存は 8bit、合成は sRGB、最終表示にディザ | メモリ半分、WebGL2 で素直、WASM SIMD で倍速、出力は全部 8bit、SAI/CSP/Procreate も 8bit。詳細は 02 |
| 画素形式 | RGBA8(プリマルチプライド)と、モノクロ用の 1 チャンネル 8bit。タイルヘッダに形式フィールドを持つ | 漫画の線画とトーンは 1ch でメモリ 4 分の 1。将来 16bit を足す余地は残す |
| タイル | 256×256、スパース(空タイルは持たない)、LRU で IndexedDB へ退避 | 600dpi の原稿を iPad mini で成立させる手段 |
| Undo | タイル差分方式、MB 上限で管理 | 既存 2 アプリの全体スナップショット方式は大キャンバスで成立しない |
| 基本操作 | 長押しの輪(ラジアルメニュー)が全操作の入口。パラメータは macbeth 版を正とする | ドット絵アプリ版より進化している(端寄せ、誤爆防止、引いたら即開く、輪の下の一覧) |
| 修飾ボタン | 左下に SHF / F / CTL / ALT(macbeth と同じ)。SHF=直線、CTL=角度スナップ、ALT=スポイト | 長押しとスポイトの衝突を解消。以前の設計書の「長押し=スポイト」は廃止 |
| ジェスチャ | 2 本指ダブルタップ Undo、3 本指ダブルタップ Redo、ピンチでズームとパン同時 | macbeth と同じ判定値を使う |
| 動画 | 手描きアニメ止まり。クリップ編集と音声トラックは対象外。音声は波形の参照表示だけ | スコープを固定し、タイムラインの設計を単純に保つ |
| 漫画 | Web 投稿と印刷の両対応。原稿は常に印刷解像度で持ち、Web は書き出し時に縮小 | 逆(Web 解像度で描いて印刷に拡大)は成立しない |
| 3D | 参照レイヤーとして扱う。操作は macbeth の体系をそのまま持ち込む。three.js を使い、必要時にだけ読み込む | クリスタの 3D が扱いづらい原因(モード切替、小さなギズモ、曖昧な関節ドラッグ)を潰す |
| 既存資産の共通化 | コピーで開始し、両方が安定してから共有パッケージ化する | 初期の変更速度を優先 |
| 性能 | 「なるべく軽く」を設計原則にする。予算は 09 に定義し、両端末で実測して守る | 両端末ともバッテリー駆動、Safari のメモリ上限が下限を決める |
| フレームワーク | 使わない。素の DOM | ドット絵アプリも macbeth も素の DOM。起動と再描画が最も軽い |
| スレッド | WASM はシングルスレッド前提。描画は OffscreenCanvas でワーカーへ | GitHub Pages では SharedArrayBuffer に必要なヘッダーを出せない |

## 経緯

- 2026-10: 初版。ドット絵アプリ(pixel-art-tool)と 3D モデリングアプリ(macbethUnity の `claude/tablet-3d-modeling-app-f6b1x5`)、以前のお絵描きアプリ設計(macbethUnity の `claude/drawing-app-design-iiiuit`)を読んだ上で確定。
